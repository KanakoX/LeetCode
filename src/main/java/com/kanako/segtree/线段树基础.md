# 线段树入门：从「区间求和」讲起

> 本文只讲**最基础**的线段树：单点修改 + 区间求和。  
> 搞懂这一版，再看进阶篇：[《线段树进阶：懒标记》](./线段树懒标记.md)。

---

## 1. 问题从哪来

有一个数组，经常要做两件事：

1. **查询**：求某一段的和，比如 `a[L] + a[L+1] + … + a[R]`
2. **修改**：把某个位置 `a[i]` 改成新值

| 做法 | 查询 | 修改 | 问题 |
|------|------|------|------|
| 暴力扫描 | O(n) | O(1) | 问得多就慢 |
| 前缀和 | O(1) | O(n) | 一改，前缀全重建 |
| **线段树** | O(log n) | O(log n) | 两边都快 |

线段树的价值：**又查又改时，两边都是对数级**

---

## 2. 核心想法

把下标区间 `[0, n-1]` 不断对半切开，建成一棵二叉树：

- **叶子**：管一个下标，存 `a[i]`
- **父亲**：管一段连续下标，存「左右儿子信息的合并」  
  （求和问题里，合并就是相加）

以 `a = [1, 3, 5, 7]`（下标 `0..3`）为例：

```text
              [0,3]  sum=16
             /              \
      [0,1] sum=4        [2,3] sum=12
      /        \          /        \
  [0]=1      [1]=3    [2]=5      [3]=7
```

每个节点预先算好自己那一段的和。查询时，不必加到底层每一个叶子，而是把目标区间拆成树上**已经算好的几块**

---

## 3. 三个基本操作

### 3.1 建树 `build`

当前节点 `p` 负责闭区间 `[nl, nr]`：

```text
如果 nl == nr:          // 叶子
    tree[p] = a[nl]
否则:
    mid = (nl + nr) / 2
    建左儿子：管 [nl, mid]
    建右儿子：管 [mid+1, nr]
    tree[p] = 左儿子 + 右儿子
```

复杂度 O(n)：每个位置对应一个叶子，内部节点大约也是 O(n) 个

### 3.2 区间查询 `query(L, R)`

在节点 `p`（管 `[nl, nr]`）上，求与目标 `[L, R]` 相交部分的和。三种情况：

```text
1. 完全无交集          → 贡献 0
2. 当前段完全被包住    → 直接返回 tree[p]   ← 关键最快
3. 部分相交            → 问左儿子 + 问右儿子
```

任意区间都能拆成 **O(log n)** 个树上的节点，所以查询是 O(log n)。

**能整段拿走就整段拿走，对不齐再往下拆。**

举例：查 `[1, 2]`

```text
根 [0,3] 只有一部分在目标里 → 往下
左 [0,1]：取出叶子 [1]
右 [2,3]：取出叶子 [2]
答案 = 3 + 5 = 8
```

### 3.3 单点修改 `update(i, val)`

把 `a[i]` 改成 `val`：

```text
一路走到叶子 i，改掉
沿路径往上：每个父亲 = 左儿子 + 右儿子
```

只更新「根到该叶子」这一条链，长度 O(log n)

举例：`a[1]` 从 3 改成 10

```text
[1]：3 → 10
[0,1]：4 → 11
[0,3]：16 → 23
右边整棵子树不用动
```

## 4. 实现细节

### 节点编号

习惯从 `1` 开始编号：

| 当前节点 | 左儿子 | 右儿子 |
|----------|--------|--------|
| `p` | `2*p` | `2*p+1` |

数组开大约 `4 * n` 即可

### 为什么是 4n？

完全二叉树最底层可能有接近 `2n` 个位置（含空位），再算上层，经验上 `4n` 够用，竞赛里也很常见

### 递归时带上区间

数组里只存 `sum`，**不存**每个节点管哪段；递归参数里带上 `[nl, nr]` 即可：

```text
build / update / query(p, nl, nr, ...)
```

## 5. Java 最小模板

```java
public class SegmentTreeSum {
    private final int n;
    private final long[] tree;  // tree[p] = 节点 p 所管区间之和

    public SegmentTreeSum(int[] a) {
        n = a.length;
        tree = new long[n * 4];
        build(1, 0, n - 1, a);
    }

    private void build(int p, int nl, int nr, int[] a) {
        if (nl == nr) {
            tree[p] = a[nl];
            return;
        }
        int mid = nl + ((nr - nl) >>> 1);
        build(p * 2, nl, mid, a);
        build(p * 2 + 1, mid + 1, nr, a);
        tree[p] = tree[p * 2] + tree[p * 2 + 1];
    }

    public void update(int i, int val) {
        update(1, 0, n - 1, i, val);
    }

    private void update(int p, int nl, int nr, int i, int val) {
        if (nl == nr) {
            tree[p] = val;
            return;
        }
        int mid = (nl + nr) >>> 1;
        if (i <= mid) update(p * 2, nl, mid, i, val);
        else update(p * 2 + 1, mid + 1, nr, i, val);
        tree[p] = tree[p * 2] + tree[p * 2 + 1];
    }

    public long query(int L, int R) {
        return query(1, 0, n - 1, L, R);
    }

    private long query(int p, int nl, int nr, int L, int R) {
        if (nr < L || nl > R) return 0;           // 无交
        if (L <= nl && nr <= R) return tree[p];   // 整段命中
        int mid = (nl + nr) >>> 1;
        return query(p * 2, nl, mid, L, R)
             + query(p * 2 + 1, mid + 1, nr, L, R);
    }
}
```

## 6. 节点里还能存什么

线段树的骨架不变，变的是「叶子存什么、父亲怎么合并」：

| 需求 | 叶子 | 合并 |
|------|------|------|
| 区间和 | `a[i]` | `左 + 右` |
| 区间最大值 | `a[i]` | `max(左, 右)` |
| 区间最小值 | `a[i]` | `min(左, 右)` |

本质都是：**把区间信息预处理到树上，查询时拆块拼接**

---

## 7. 小结

1. **叶子 = 元素，父亲 = 左右合并**
2. **查询 = 把区间拆成 O(log n) 块现成答案**
3. **单点修改 = 只更新祖先链**
4. **节点存什么，取决于你要维护什么**

线段树是一棵「按区间二分、预先汇总」的二叉树。从区间求和入门，是最顺的路径
